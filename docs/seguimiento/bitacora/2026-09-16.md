## Reproduccion

En el frontend se cambio solamente ScreenStudio.tsx: cleanup del srcObject y keys
distintas para preview y grabacion. React podia reutilizar el video con MediaStream
finalizado, ocultando el archivo que si funcionaba al descargarlo. Azure playback
ahora fuerza inline y MIME mediante respuesta firmada, sin headers de autenticacion
adicionales para el elemento video.

Prueba de navegador con MediaRecorder/canvas real: srcObject=null, readyState=4,
videoWidth=320, tiempo de reproduccion mayor a cero y pixeles no negros. Capturas
desktop y movil revisadas. Script reproducible: scripts/check_frontend_playback.cjs
(Playwright, Edge y servidor Vite; no necesita claves ni sube contenido).
